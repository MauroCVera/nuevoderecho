# Facultad Digital

Ayudame a crear una a aplicacion para Android/Celular que pueda seguir el patron de diseño de las imagenes compartidas, con un panel de bienvenida que al iniciar pida una contraseña y usuario, el cual se podrà crear desde el mismo panel; el panel debe tener la palabra "Bienvenido/a a Facultad de Derecho" con la Fuente Bebas Neue en letras blancas y el fondo un color azul francia #0000ff. Despues el sistema debe llevar al usuario a la pantalla de inicio (en caso que el usuario ya hubiera abierto sesion previamente, pasa directamente a la pantalla de inicio) esta pantalla debe ser como las dos primeras imagenes adjuntas con un boton animado que diga "Entrar" en letras Bebas Neue con color blanco. El menu principal deberia respetar las imagenes, y cada seccion marcada en las imagenes de muestra, formar una nueva pestaña en la parte inferior de la pantalla en secciones/botones "Carreras" "Institucional" "Info" "Herr. Digitales" "Mi Carrera"
